# rpbostick.github.io

Patrick Bostick's demo site, served at https://rpbostick.github.io/. A Vite + React + TypeScript app with one page per project; GitHub Actions (`.github/workflows/deploy.yml`) builds it and deploys to GitHub Pages on every push to `main`. For that workflow to publish, the repository's Pages source must be set to **GitHub Actions** (Settings → Pages → Build and deployment → Source), not "Deploy from a branch".

```
npm install
npm run dev      # local preview
npm run build    # type-check and build into dist/
npm run lint
```

## Pages

| URL | HTML entry | Code |
| --- | --- | --- |
| `/` | `index.html` | `src/index/` |
| `/figurewright/` | `figurewright/index.html` | `src/figurewright/`, images in `public/figurewright/` |

Shared styles and hooks live in `src/shared/`. A new page needs its own `<name>/index.html`, a `src/<name>/main.tsx`, and an entry in `build.rollupOptions.input` in `vite.config.ts`.

## Credits

Animated components under `src/reactbits/` are from [React Bits](https://reactbits.dev) (MIT + Commons Clause: they are used only as part of this site, not published separately). `src/reactbits/LICENSE.md` lists which components are copied and what was changed.

The figurewright hero's colour loop lives in `src/figurewright/palette.ts` and `src/figurewright/colourDrive.ts`; `npm run check:palette` prints every stop with its contrast against both hero backgrounds, and `npm run check:colour-drive` checks the drift, wheel and resume timing. Dragging through the hero morphs the wave pattern through the presets in `src/figurewright/patternDrive.ts`; `npm run check:hero-controls` checks the drag gain, momentum, the middle-click toggle and which clicks activate the hero.

Every page has a System / Light / Dark switch in the top right (`src/shared/ThemeSwitch.tsx`, `src/shared/theme.ts`). The choice is saved in `localStorage` and set as `data-theme` on `<html>` by a small inline script in each `index.html` before first paint; script that draws in theme colours reads `useTheme()` rather than the `prefers-color-scheme` media query.

The figurewright images use head, hand and shoe art from [Open Peeps](https://www.openpeeps.com/) by Pablo Stanley (CC0).

## Third-party licences

`public/THIRD_PARTY_LICENSES.txt` (this site's bundle, React Bits and colorwright) and `public/skywright/THIRD_PARTY_LICENSES.txt` (the skywright demo) are generated by `scripts/third-party-licenses.mjs` from [license-checker](https://www.npmjs.com/package/license-checker) output, and linked from the index and figurewright footers. Regenerate them whenever the dependencies change or the skywright demo is re-exported:

```
# in skywright/example, after the export
npx --yes license-checker --production --json > /tmp/skywright-production.json
# in this repository
npx --yes license-checker --production --json > /tmp/site-production.json
node scripts/third-party-licenses.mjs skywright /tmp/skywright-production.json
node scripts/third-party-licenses.mjs site /tmp/site-production.json
```

The script reads each package's licence file from disk, so run it on the machine where both `node_modules` trees are installed. It leaves out the root project (license-checker marks it `private`); packages that ship no licence file are listed with their declared licence.
