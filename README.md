# rpbostick.github.io

Patrick Bostick's demo site, served at https://rpbostick.github.io/. A Vite + React + TypeScript app with one page per project; GitHub Actions (`.github/workflows/deploy.yml`) builds it and deploys to GitHub Pages on every push to `main`. For that workflow to publish, the repository's Pages source must be set to **GitHub Actions** (Settings → Pages → Build and deployment → Source), not "Deploy from a branch".

```
npm install
npm run dev      # local preview
npm run build    # type-check and build into dist/
npm run lint
```

Shared styles and hooks live in `src/shared/`. A new page needs its own `<name>/index.html`, a `src/<name>/main.tsx`, and an entry in `build.rollupOptions.input` in `vite.config.ts`.

### Host mode

colorwright and skywright are copied into `public/` as exported and never edited here. `npm run build` puts their copies in `dist/` into host mode (`scripts/hostMode.ts`, a Vite plugin): it adds `data-host-controls` and `data-host-backdrop` to `<html>`, so the demo hides its own theme switch, leaves room at the top right and turns its page background transparent, and it adds the page's host bundle from `src/host/`. The build fails if either page no longer has exactly one `<html` tag and one `</head>`. `npm run dev` serves the demos as they are, without host mode; use `npm run build` and `npx vite preview` to see them hosted.

## Credits

Animated components under `src/reactbits/` are from [React Bits](https://reactbits.dev) (MIT + Commons Clause: they are used only as part of this site, not published separately). They are generated by [reactbits-kit](https://github.com/rpbostick/reactbits-kit) (`npx rbx add <Component> --to src/reactbits`, profile and upstream commit pinned in `src/reactbits/reactbits-kit.json`), which applies our changes to the upstream files; each component's `CHANGES.md` lists them, and `src/reactbits/LICENSE.md` has React Bits' license. `npm run lint` runs `rbx check`, which fails if a generated file has drifted from what the kit produces (it downloads the pinned upstream files, so it needs the network).

The figurewright hero's color loop lives in `src/figurewright/palette.ts` and `src/figurewright/colorDrive.ts`; `npm run check:palette` prints every stop with its contrast against both hero backgrounds, and `npm run check:color-drive` checks the drift, wheel and resume timing. The wave pattern drifts through the presets in `src/figurewright/patternDrive.ts` on its own, and the pattern tag and its arrows step it; dragging stirs local ripples without changing the pattern, gently turns the pattern like the inside of a ball (reactbits-kit's `sphereSpin` module, a tenth of the turn that would keep the point under the pointer; on release the ball spins on the way it was pulled and slows over 3 to 9 s; `npm run check:sphere-spin`), and stretches the whole field towards the pointer like a sheet through a spring in reactbits-kit's `clothFollow` module, which glides on after release without springing back (`npm run check:cloth-follow`). `npm run check:hero-controls` checks the drift, the steps, the drag momentum, the middle-click toggle and which clicks activate the hero. A dev-only preview of the six patterns side by side is at `/dev/wave-patterns.html` under `npm run dev`; it is not part of the build.

Every page has a System / Light / Dark switch in the top right (`src/shared/ThemeSwitch.tsx`, `src/shared/theme.ts`). The choice is saved in `localStorage` and set as `data-theme` on `<html>` by a small inline script in each `index.html` before first paint; script that draws in theme colors reads `useTheme()` rather than the `prefers-color-scheme` media query.

The demo pages (`/figurewright/`, `/colorwright/`, `/skywright/`) have a control cluster there instead (`src/shared/ControlCluster.tsx`): the theme switch, an Animations toggle and, on skywright, Sun, Rain and Snow. The Animations choice (`src/shared/motion.ts`) is saved in `localStorage` as `motion`; with nothing saved it follows `prefers-reduced-motion`. With animations off, every background shows one still frame, and every animation loop pauses while the tab is hidden.

colorwright has the React Bits Iridescence behind it and skywright the Aurora (`src/backdrops/`). The aurora drifts between sunny, rainy and snowy feels, and Sun, Rain and Snow hold one for 20 s (`src/backdrops/weather.ts`). Each background sits under a wash of the demo's page color (`src/backdrops/wash.ts`); `npm run check:backdrops` checks that the demos' muted text, and colorwright's faint text, stay at 4.5:1 or more over every background color, and `npm run test:unit` runs the unit tests for the motion state, the weather timing and host mode.

The figurewright images use head, hand and shoe art from [Open Peeps](https://www.openpeeps.com/) by Pablo Stanley (CC0).

## Third-party licenses

`public/THIRD_PARTY_LICENSES.txt` (this site's bundle, React Bits and colorwright) and `public/skywright/THIRD_PARTY_LICENSES.txt` (the skywright demo) are generated by `scripts/third-party-licenses.mjs` from [license-checker](https://www.npmjs.com/package/license-checker) output, and linked from the index and figurewright footers. Regenerate them whenever the dependencies change or the skywright demo is re-exported:

```
# in skywright/example, after the export
npx --yes license-checker --production --json > /tmp/skywright-production.json
# in this repository
npx --yes license-checker --production --json > /tmp/site-production.json
node scripts/third-party-licenses.mjs skywright /tmp/skywright-production.json
node scripts/third-party-licenses.mjs site /tmp/site-production.json
```

The script reads each package's license file from disk, so run it on the machine where both `node_modules` trees are installed. It leaves out the root project (license-checker marks it `private`); packages that ship no license file are listed with their declared license.
